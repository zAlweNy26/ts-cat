# catPaths

> `const` **catPaths**: `object`

It contains various paths and URLs used in the application.

## Type declaration

| Name | Type | Default value | Description |
| ------ | ------ | ------ | ------ |
| <a id="assetspath"></a> `assetsPath` | `string` | - | The path to the assets directory. |
| <a id="assetsurl"></a> `assetsUrl` | `string` | - | The URL to the assets directory. |
| <a id="basepath"></a> `basePath` | `string` | 'src' | The base path of the application. |
| <a id="baseurl"></a> `baseUrl` | `string` | - | The base URL of the application. |
| <a id="pluginspath"></a> `pluginsPath` | `string` | - | The path to the plugins directory. |
